# **Chess Journey: Python Chess Game with Custom GUI and AI**

Полностью переработанный школьный проект, созданный на основе серии туториалов ["Chess Engine in Python" от Eddie Sharick](https://www.youtube.com/watch?v=EnYui0e73Rs&list=PLBwF487qi8MGU81nDGaeNE1EnNEPYWKY_). 

В этом проекте реализована логика шахматных правил с помощью библиотеки [python-chess](https://github.com/niklasf/python-chess), собственные компоненты графического интерфейса пользователя (GUI) с использованием [pygame-ce](https://github.com/pygame-community/pygame-ce) и [pygame-gui](https://github.com/MyreMylar/pygame_gui), управление конфигурацией через [Pydantic Settings](https://github.com/pydantic/pydantic-settings), а также интеграция с сильным шахматным движком [Stockfish](https://stockfishchess.org/) (что позволяет играть как против компьютера, так и самостоятельно).

> [!NOTE]  
> **Этот репозиторий переведён в архив.** См. раздел [Конец путешествия](#конец-путешествия) для контекста.

## **Быстрый старт**

### **Предварительные требования**
- Менеджер пакетов [Pixi](https://pixi.sh/latest/).

### **Установка и запуск**

1. **Клонирование репозитория**
    ```bash
    git clone https://github.com/Sierra-Arn/chess-journey.git
    cd chess-journey
    ```

2. **Установка зависимостей**
   ```bash
   pixi install
   ```

3. **Настройка конфигурации окружения**
   ```bash
   pixi run copy-env
   ```

4. **Настройка Stockfish**
    - Скачайте подходящий [бинарный файл Stockfish](https://stockfishchess.org/download/) для вашей платформы.
    - Поместите файл в директорию `src/chess_game/assets/stockfish/`.
    - При необходимости обновите путь к файлу в файле конфигурации `.env`.

5. **Запуск шахматной игры**
    ```bash
    pixi run launch-chess-game
    ```
    Если вы хотите более подробно понять архитектуру, ознакомьтесь с [документацией по архитектуре](docs/architecture_ru.md).

6. **[Опционально] Запуск оригинального кода**
    ```bash
    pixi run setup-legacy-images
    pixi run launch-legacy-code
    ```

## **Известные проблемы**

- **Рокировка в Chess960**  
Рокировка в вариантах Chess960 не работает из-за конфликта обработки ввода в графическом интерфейсе. Рокировка в Chess960 требует перемещения короля на клетку ладьи, но текущий обработчик кликов мыши выбирает фигуру ладьи на этой клетке вместо того, чтобы обработать её как допустимую клетку назначения для хода короля, что предотвращает выполнение рокировки. Однако, когда ИИ делает ход рокировки, он работает правильно, поскольку ИИ использует библиотеку python-chess напрямую.

- **GameScreen.update()**  
Метод `update()` нигде явно не вызывается в коде, но по какой-то причине необходим для правильного отображения таймеров. Удаление этого неиспользуемого метода нарушает способность таймера правильно отображать текущие значения времени.

- **Настройка ИИ**  
На текстовые поля ввода можно кликнуть, когда активны настройки ИИ (визуальный баг, ввод текста не происходит).

## **Возможные улучшения**

- **Улучшенный интерфейс слайдеров**  
Слайдеры в настоящее время не отображают свои текущие числовые значения. Было бы здорово добавить визуальную обратную связь, показывающую текущее значение, и в идеале обновлять отображаемое значение в реальном времени при перетаскивании ползунка, обеспечивая немедленную обратную связь по настройке параметров.

- **Запись ходов**  
Реализовать правильную запись и отображение ходов игры в стандартной шахматной нотации. В оригинальном коде туториала была базовая функциональность отображения ходов, но эта функция была намеренно опущена в переработке для сосредоточения на улучшениях основной архитектуры. Добавление этого функционала вернуло бы пользователям полную историю игры.

- **Надежная обработка ошибок**  
Добавить правильную валидацию пользовательских настроек и реализовать комплексную проверку на `None` во всем коде для повышения стабильности приложения.

- **Полноценная превращение пешки**  
Расширить превращение пешки для поддержки всех типов фигур в дополнение к ферзю.
- **Правильное управление компоновкой UI**  
Заменить жестко заданные позиции, размеры и отступы на правильную систему компоновки для виджетов и экранов.
- **Темы PyGame GUI**  
Добавить темы PyGame GUI для улучшения визуального оформления и пользовательского опыта.

## **Конец путешествия**

Этот проект никогда не задумывался как законченное шахматное приложение. Он создавался как учебной проект, цель которого — обучение через практику. Изначально проект преследовал цель создания минимально жизнеспособного продукта (MVP), демонстрирующего современные практики разработки на Python, объектно-ориентированную архитектуру и интеграцию с современными библиотеками, такими как `python-chess`, `pygame-ce` и `pygame_gui`.

**Известные проблемы** и **Возможные улучшения**, описанные ранее, были намеренно оставлены без исправления как сознательные решения, принятые в духе быстрой разработки. Кроме того, создание полнофункциональной игры в PyGame предполагает использование Python, а выбор Python для игр — сомнительное решение, когда существуют специализированные высокопроизводительные альтернативы, такие как [Godot](https://github.com/godotengine/godot), для серьезной разработки игр.
