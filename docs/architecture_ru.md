# **Обзор архитектуры**

## **I. Экран настройки**
— это начальный интерфейс приложения, предназначенный для конфигурации параметров шахматной партии перед началом игры.

### **i. Основная структура макета**

Компонентная архитектура экрана настройки включает следующие элементы:

1. **Разделы настройки игроков** (два `PlayerSetupWidget`)
    - **Настройка белого игрока** — конфигурация параметров для белого игрока.
    - **Настройка чёрного игрока** — конфигурация параметров для чёрного игрока.

2. **Настройки игры**
    - **Выпадающий список режима игры** — выбор между стандартными шахматами и вариантами Chess960.
    - **Выпадающий список ориентации доски** — определение цвета, расположенного внизу доски.

3. **Кнопка «Начать игру»** — центрированный элемент управления для запуска игры с текущими настройками.

### **ii. Компоненты виджета настройки игрока**

Каждый `PlayerSetupWidget` содержит интерактивные элементы управления параметрами игрока:

- **Выпадающий список типа игрока** — переключение между `HUMAN` и `AI`.
- **Поле ввода имени** — текстовое поле для имени человека (отключено для ИИ).
- **Ползунок сложности ИИ** — настраиваемый уровень сложности (1–20, отключен для человека).
- **Ползунок контроля времени** — установка ограничения времени (1–60 минут).

### **Динамическое поведение интерфейса**

**Адаптивная логика** компонентов обеспечивает согласованность настроек:
- При выборе типа `AI`: **отключение** поля имени, **включение** ползунка сложности.
- При выборе типа `HUMAN`: **включение** поля имени, **отключение** ползунка сложности.

## **II. Игровой экран**
— это основной интерфейс приложения, где происходит шахматная партия с учетом настроек, заданных на предыдущем экране.

### **Ключевые компоненты**

Центральная архитектура игрового экрана включает:

1. **Виджет шахматной доски** (`ChessBoardWidget`)
    - **Центральная интерактивная доска** — основное поле взаимодействия с фигурами.
    - **Поддержка Chess960** — автоматическая синхронизация с случайными начальными позициями.

2. **Виджеты таймеров игроков** (два `PlayerTimerWidget`)
    - **Таймер белого игрока** — отображение имени и обратного отсчета времени.
    - **Таймер чёрного игрока** — отображение имени и обратного отсчета времени.

3. **Отображение окончания игры**
    - **Наложенная надпись** — визуализация результата партии после её завершения.

### **Динамическое поведение**

**Интерактивная логика** обеспечивает плавный игровой процесс:

- **Подсветка ходов** — автоматическое выделение выбранной фигуры и допустимых перемещений.
- **Автоматизация ИИ** — планирование вычисления хода при активности искусственного интеллекта.
- **Переключение таймеров** — автоматическое обновление времени после каждого хода.
- **Проверка завершения** — немедленное определение и отображение условий окончания игры.
